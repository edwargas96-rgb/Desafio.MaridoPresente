# Imagens do quiz

Coloque aqui os arquivos com estes nomes (ou ajuste os caminhos em `js/config.js`).
Enquanto o arquivo não existir, o quiz mostra um espaço tracejado no lugar.

| Arquivo | Onde aparece | Proporção sugerida |
|---|---|---|
| `hero.jpg` | Tela de abertura, abaixo da logo | 16:9 (ex.: 1280x720) |
| `logo.webp` | Logo na abertura (já incluída) | quadrada |
| `resultado.jpg` | Tela de resultado | 16:9 (ex.: 1280x720) |
| `jogo-buque.jpg` | Abertura do jogo do buquê | 16:9 |
| `jogo-palavras.jpg` | Abertura do jogo das palavras | 16:9 |
| `jogo-bandeja.jpg` | Abertura do jogo da bandeja | 16:9 |
| `jogo-memoria.jpg` | Abertura do jogo da memória | 16:9 |
